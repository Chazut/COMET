# COMET 1.0.0 beta 3

## Features

- **Squad tactics** let bots cover building exits or pair a grenade throw with a teammate holding an angle.
- **PMCs recognize bosses and guards.** Cautious personalities expect backup early in a raid, including around faction patrols.
- **Local lighting** makes players and bots harder to spot in shade. Bots remember recent sightings.
- **Magazine recovery** lets bots return after combat for a mag dropped during an emergency reload.

## Changes

- Bots share lighting checks for the same target. Performance reports flag frames that exceed the budget.

## Fixes

- Bots skip bare bushes when choosing cover in autumn and winter. Solid trunks still count.
- Bots choose compatible ammo more reliably when reloading.
