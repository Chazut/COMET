**COMET beta 1 is ready for some weekend testing!**

This is a **very early beta**: not all the features are there yet, not everything works properly, and there are still bugs. But at least you can give it a try this weekend!

All the features in this beta come from **R_F's work**, adapted and tweaked to my taste. I've got more ideas to add later. **A huge thank you to R_F - none of this would be possible without him.**

Requires **original SAIN 4.5.1** on **SPT 4.1.6**. It doesn't replace SAIN, and **ORBIT is optional**. Settings: <https://127.0.0.1:6969/comet>

Keep **Quiet logging OFF** for testing. If something goes wrong, send me the COMET diagnostics + `LogOutput.log`, ideally with the bot's name and when it happened.

Fika support is experimental; use both ZIPs if you're testing with Fika.
